Class SKDiskCacheTileProvider

Namespace
SkiaSharp.Extended

SkiaSharp.Extended.dll

A persistent cache decorator backed by the local filesystem. It wraps an inner provider (for example SKHttpTileProvider) and stores fetched tiles on disk using hashed, bucketed filenames with a configurable expiry.
